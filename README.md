# One Health genomic surveillance reveals structured urban rabies transmission and major surveillance gaps

This repository contains the analysis code, processed data, and supporting materials accompanying the preprint:

> **One Health genomic surveillance reveals structured urban rabies transmission and major surveillance gaps**

**Authors**

Kirstyn Brunker¹²*, Alejandra Dávila-Barclay¹³, Elvis W. Díaz³, Sandeep Kasaragod¹², Rowan Durrant¹⁴, Katie Hampson¹, Edith Zegarra⁵, Ynés Monroy⁵, Ricardo Castillo-Neyra³⁶⁷*

## Repository contents

- `analysis/` – analysis workflows, phylogenetic and phylogeographic analyses
- `scripts/` – reusable analysis scripts
- `processed_data/` – processed datasets used in the analyses
- `raw_data/` – original data source
- `figures/` – figures generated for the manuscript
- `supplementary/` – supplementary materials

Large intermediate files (e.g. BEAST outputs, alignments, and GIS source files) are excluded from this repository.

## Data availability

Consensus genome sequences generated in this study will be deposited in GenBank following peer review. Accession numbers will be added once available.
